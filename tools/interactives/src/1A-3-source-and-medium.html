A wave travels along a light rope that is joined to a second rope. The hand shaking the end is the source. Each rope is a medium. What changes when the wave crosses the join?

Two ropes joined at x = 5 m

Crossing into a new medium, the frequency stays the same (the source sets it) and the speed changes (the medium sets it), so the wavelength changes: $\lambda = \dfrac{v}{f}$.
