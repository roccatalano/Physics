Light bounces between two mirrors inside a rocket. Light has the same speed $c$ for every observer. Seen from Earth, the moving light takes a longer path, so each tick takes longer.

Same clock, two frames of reference

The crew measure the proper time $t_0$ and proper length $L_0$. Earth measures a longer time $t = \gamma t_0$ and a shorter length $L = L_0 / \gamma$.
