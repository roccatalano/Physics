# Year 11 Physics lesson index (Cambridge VCE Physics Units 1&2)

Built 18 Nov 2026 by nine agents, one per chapter. The format is in `SCHEMA.md`.
This folder holds copied Cambridge text and images. Use it for your own teaching only, and keep it off the public GitHub site.

## What's here
| | Count |
|---|---|
| Success criteria (from the Chapter Checklists) | 154 |
| Worked examples (textbook, plus a few Skills boxes) | 98 |
| Check-in questions (Do now pool) | 239 |
| Section questions | 342 |
| Worksheet questions (by part) | 257 |
| Review questions (exit ticket pool) | 237 |
| Images (figures, graphs, diagrams, question pictures) | 652 |

Each `chNN` folder has `chNN.json` (criteria, review questions, exit candidates, summary), one JSON per section (everything for the lesson, plus a `wedo_plan`), and `img/`.
Every question has a `kind` tag (recall, explain, calc or graph), a `size` tag (quick, medium or long), a `phase` tag (the lesson phase it suits) and a `criteria` tag (the success criteria it covers).

## Not indexed
- Chapter tests: recorded only as question and mark counts.
- Pracs: title and aim only.
- Unit 2 options and the AoS 3 investigation.
