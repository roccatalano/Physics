## Lesson shape (as agreed for the old planner; confirm)
Do now (3 retrieval questions: last lesson / last week / last term, from Cambridge check-ins) → Learning goals (3, one per card) → Key ideas (definitions | formulas) → APK (prior knowledge, not retrieval) → New knowledge → We do (Cambridge worked examples, each followed by a You try) → Independent practice (Cambridge section questions or worksheet) → Exit ticket (one question per learning goal, from Cambridge, with red/amber/green self-rating).
- Each lesson's steps must add up exactly to the lesson length.

## Slides and guided sheets (one each per lesson)
- **Deck:** a self-contained HTML deck with timers, reveals and embedded media. It must work offline.
- **Look:** dark navy background with faint moving wave lines; rounded cards with coloured left edges; Space Grotesk headings and Inter body text. Keep text sparse: less is more.
- **Writing:** no em or en dashes, and no AI-sounding filler.
- **Title slide:** tags for "Unit N", "AoS N: name" and "Lesson N" above the lesson title, with the lesson sequence and minutes on the right.
- **Headings:** the big heading on each slide is the phase name (Do now, Learning goals, APK, New knowledge, We do, Independent practice, Exit ticket). Don't write minute counts on slides; every phase gets a timer instead.
- **Timers:** start automatically when you reach a slide. A phase's timer keeps running across all of that phase's slides and resets when you leave the phase.
- **Solutions:** shown in shadowed boxes that drop down or slide in, worked step by step. In Do now and Exit ticket, each question and its solution sit in a row of equal height.
- **Animations:** animate where it helps (waves and graphs), with explanation cards alongside.
- **Maths:** always rendered with KaTeX, pre-rendered with the fonts embedded so it works offline.
- **Mini whiteboards:** not used. Everything students write goes on the guided sheet.
- **Guided sheet:** black and white, double-sided A4, following the slides in order. It ends with a cut-off exit ticket strip that has red/amber/green circles for each goal. Build it in HTML and print it to PDF.
- **Visual check:** check every slide and both sheet pages visually (with solutions showing) before handing over.
- **Where it lives:** working copies go in `Desktop\2027 Planning\Year 11 Physics\Slides\`. The old L01/L02 decks there were built on Pearson: reuse their style and code (`Slides\src\`), not their content.
